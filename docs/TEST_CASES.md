# 测试用例（TEST_CASES.md）

本文件包含两部分：

- **A. 自动化测试**：`npm test` 运行，共 33 个用例，覆盖核心规则与工程健壮性；
- **B. 手工测试用例**：面向浏览器 UI 的功能验收，覆盖需求文档 §3 全部页面与交互。

---

## A. 自动化测试

运行方式：`npm test`（Node ≥ 20，零依赖）。

### A.1 风险引擎 `tests/engine.test.js`（21 个用例）

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| E01 | 空历史画像 | sampleCount=0、白名单空、均值/最高/区间/时段均为 null |
| E02 | 白名单计算 | 历史 ≥2 次的收款人进入白名单并按次数排序，1 次的不进入 |
| E03 | 金额统计 | 均值、最高值、常见区间（均值±标准差）计算正确 |
| E04 | 常用时间段 | 取中央 80% 区间（十分位~九十分位） |
| E05 | 深夜交易统计 | 23:00-06:00 的交易计入 nightCount |
| E06 | 时段格式化 | 9 → "09:00"；区间 → "09:00 - 21:00"；null → null |
| E07 | 非常规时段边界 | 23:00 起算；06:00 不算（含 05:59）；白天不算 |
| E08 | 权重合计 | 30+25+25+20 = 100 |
| E09 | 陌生收款人 +30 | 非白名单 +30；白名单收款人 0 分 |
| E10 | 白名单门槛 | 历史仅 1 次的收款人仍未达门槛，仍 +30 |
| E11 | 深夜交易 +25 | 23:30 交易 55 分（陌生30+深夜25）；白天 30 分 |
| E12 | 超大金额 +25 | 超均值 3 倍或超历史最高值 1.5 倍均触发 |
| E13 | 金额新高仅提示 | 超历史最高但未达 1.5 倍 → 不加分、仅提示点 |
| E14 | 无历史不比对金额 | 仅陌生 +30，附"暂无历史"提示 |
| E15 | 附言敏感词 +20 | 含"保证金"等词 → 陌生30+敏感词20=50 |
| E16 | 正常附言不加分 | "房租"等正常附言不影响分数 |
| E17 | 分数封顶 | 多规则叠加后不超过 100 |
| E18 | 等级阈值 | 0-29 低 / 30-69 中 / 70-100 高 |
| E19 | 返回结构 | 返回 score/level/points，且风险点 ≥3 时等级为高风险 |
| E20 | 入参校验 | 缺收款人 / 金额非数 / 金额≤0 → 返回 error |
| E21 | 敏感词匹配 | 命中返回关键词；无附言/正常附言返回空数组 |

## B. 手工测试用例（浏览器 UI 验收）

前置条件：启动应用（`npm start` 或任意部署方式），浏览器打开首页。

| 编号 | 前置条件 | 操作步骤 | 预期结果 |

| U01 | 打开首页 | 查看页面结构 | 顶部为应用名与两个 Tab；主区为转账表单；右下角有悬浮助手图标；页脚含 96110 提示 |

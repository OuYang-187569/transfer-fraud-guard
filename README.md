# 转账反诈守门工具（Transfer Fraud Guard）

一款面向个人用户的**转账安全辅助与反诈识别网页应用**。系统记录并学习用户的历史转账习惯（常用收款人、转账金额区间、常用时间段），在用户发起新转账时实时分析交易特征并给出 **0-100 分**诈骗风险评分、风险等级与可疑点说明，并在转账确认环节提供**二次确认弹窗**；同时内置**悬浮 AI 反诈咨询助手**，辅助识别潜在诈骗风险。

> 本工具为转账安全辅助检测，**不涉及真实资金操作**；遇疑似诈骗请拨打 **96110** 反诈专线。

---

## 功能特性

| 模块 | 说明 |
| --- | --- |
| 转账主页（核心操作区） | 新建转账表单（收款人 / 账户 / 金额 / 交易时间 / 附言），点击「安全检测并转账」触发风险评估 |
| 风险评估二次确认弹窗 | 展示交易信息、0-100 风险分、风险等级标签（低 / 中 / 高）、可疑风险点列表；提供「取消转账 / 继续转账确认 / 一键向 AI 助手咨询」 |
| 习惯画像与历史记录页 | 常用收款人白名单、常规金额区间（均值 ± 标准差）、常用时间段、历史转账明细；支持手动新增基准记录完善画像 |
| 悬浮 AI 反诈助手 | 常驻右下角，可展开 / 收起；自动或一键带入当前转账上下文；结合反诈知识库给出分析与防骗建议 |

## 核心业务规则（需求文档 §4）

### 习惯画像计算（§4.1）

1. **常用收款人白名单**：历史转账次数 **≥ 2 次** 的收款账户自动计入白名单。
2. **常规金额区间**：以历史金额均值 ± 标准差为常规区间；单笔金额超过历史最高值的 **1.5 倍** 判定为金额异常。
3. **常用时间段**：统计历史交易小时的中位 80% 区间（十分位 ~ 九十分位）作为常用时间段；**23:00 - 次日 06:00** 判定为非常规时段。

### 风险评分与等级判定（§4.2）

系统基础风险分为 0 分，按命中风险项加权累计，**满分 100 分**：

| # | 风险项 | 加分 | 说明 |
| --- | --- | --- | --- |
| 1 | 陌生收款人 | +30 | 收款人不在常用白名单（历史交易 < 2 次） |
| 2 | 异常时段交易 | +25 | 23:00 - 次日 06:00 期间发起 |
| 3 | 超大金额异常 | +25 | 超过日常均值 3 倍，或超过历史最高值的 1.5 倍 |
| 4 | 附言含疑似诈骗敏感词 | +20 | 保证金 / 解冻 / 刷单 / 验证码 / 退款 等（**补充规则**，见下） |

**风险等级**：`0-29 低风险`、`30-69 中风险`、`70-100 高风险`。

> **规则假设说明**：需求文档 §4.2 仅列出规则 1-3（合计 80 分）。为补全 0-100 分制，本实现补充第 4 条规则「附言含疑似诈骗敏感词 +20 分」，敏感词库位于 `src/js/engine.js` 的 `SENSITIVE_KEYWORDS`，可按需增删。若需严格按 80 分制运行，将 `RISK_RULES.SUSPICIOUS_NOTE` 置为 0 即可。

## 技术栈

- **纯前端单页应用**（HTML + CSS + 原生 JavaScript ESM），零运行时依赖
- 数据持久化：浏览器 `localStorage`（数据不出本机，隐私友好）
- 本地开发 / 部署服务器：Node.js 内置 `http`（`server.js`，零依赖）
- 生产部署：Nginx 静态托管 / Docker
- 测试：Node 内置测试运行器 `node --test`（零依赖）
- AI 反诈助手：**规则化离线知识库**（`src/js/chatbot.js`），确定性、可测试；可替换为大模型 API（见「AI 助手说明」）

## 快速开始

要求：**Node.js ≥ 18**（测试推荐 ≥ 20）。无任何第三方依赖，无需 `npm install`。

```bash
# 1. 启动本地服务器（默认 http://localhost:3000）
npm start
# 自定义端口
PORT=8080 npm start

# 2. 运行自动化测试（33 个用例）
npm test
```

浏览器打开 `http://localhost:3000` 即可使用。首次使用建议在「习惯画像与历史记录」页点击**载入示例数据**，快速体验完整画像与风险评估效果。

## AI 助手说明

当前「AI 反诈助手」为**规则化离线知识库**（覆盖冒充客服、刷单返利、杀猪盘、冒充公检法、贷款征信、验证码、中奖、出借账户等常见骗局），结合当前转账上下文（收款人、金额、时间、已识别风险点）给出分析与建议：

- 输出确定性、可单元测试（见 `tests/chatbot.test.js`）；
- 不依赖网络与 API Key，离线可用；
- 如需接入真实大模型：替换 `src/js/chatbot.js` 中 `getBotReply()` 的实现即可（保留输入输出签名：`(input, context) => { text, matched }`），UI 层无需改动。

## 数据与隐私

- 全部数据保存在浏览器 `localStorage`（键 `transfer_guard_history_v1`），不上传任何服务器；
- 「继续转账确认」仅模拟确认，不会发起真实资金操作；
- 清空数据：历史页「清空历史」按钮，或浏览器清除站点数据。

## 测试

- **自动化测试**：`npm test`，覆盖风险引擎全部规则与边界、AI 助手知识库、静态服务器与路径穿越防护，共 33 个用例。
- **手工测试用例**：见 [`docs/TEST_CASES.md`](docs/TEST_CASES.md)（含前置条件、步骤与预期结果）。
